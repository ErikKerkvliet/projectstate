Connecting an agent

Endpoint {{ base_url }}/mcp (Streamable HTTP; {{ base_url }}/x402/mcp is the same server). No account and no API key: the wallet that pays is the identity, and each wallet gets its own isolated projects.

The payment handshake

  1. Call any tool. Without credit the result is isError: true with an x402 v2 PaymentRequired object in structuredContent (and the same JSON as text in content[0].text): scheme exact, network {{ x402.network }}, USDC, and the amount.
  2. Sign the payment with your wallet and retry the same call with the payload in _meta["x402/payment"].
  3. The result carries the settlement receipt in _meta["x402/payment-response"] and a credit token in _meta["projectstate/x402-credit"].
  4. Later calls draw from the credit: on a session-based connection automatically, otherwise by sending the credit token as Authorization: Bearer xc_… or in _meta["projectstate/x402-credit"]. When the credit runs out the next call answers with PaymentRequired again.

Amounts: ${{ pack }} per payment on a session-based connection, ${{ minpay }} minimum per call without one. Unused credit stays on your wallet address.

Clients

TypeScript (Vercel AI SDK)

import { experimental_createMCPClient as createMCPClient } from "ai";
import { StreamableHTTPClientTransport } from "@modelcontextprotocol/sdk/client/streamableHttp.js";
import { withPayment } from "x402-mcp";

const client = await createMCPClient({
  transport: new StreamableHTTPClientTransport(new URL("{{ base_url }}/mcp")),
}).then((c) => withPayment(c, { account: process.env.PRIVATE_KEY }));

Python (official MCP SDK + x402)

from eth_account import Account
from mcp import Client
from x402 import x402Client
from x402.mechanisms.evm.exact import register_exact_evm_client
from x402.mechanisms.evm.signers import EthAccountSigner
from x402.schemas import PaymentRequired

x = x402Client()
register_exact_evm_client(x, EthAccountSigner(Account.from_key(KEY)))
async with Client("{{ base_url }}/mcp") as mcp:
    r = await mcp.call_tool("project_open", {"project": "my-app"})
    pr = r.structured_content                      # PaymentRequired
    pay = (await x.create_payment_payload(PaymentRequired(**pr))).model_dump(by_alias=True, exclude_none=True)
    r = await mcp.call_tool("project_open", {"project": "my-app"}, meta={"x402/payment": pay})
    token = r.meta["projectstate/x402-credit"]     # reuse on the next calls
    r = await mcp.call_tool("recall", {"project": "my-app", "query": "auth"},
                            meta={"projectstate/x402-credit": token})

A worked example ships with the server as scripts/x402_agent_demo.py.

Clients that cannot pay (Claude.ai connectors, Cursor, VS Code today) can reach the endpoint but every call answers with PaymentRequired.

plan_check is the one to call before you start something. You say what you intend to do in one line; it runs three targeted searches and returns only what would change your mind: attempts that already failed at this, decisions still in force that constrain it, and open tasks that overlap. Cheaper than repeating work that failed once.

Prices are published per tool in tools/list under _meta.priceUsd. Every successful result carries _meta["projectstate/chargedUsd"] and _meta["projectstate/balanceUsd"]. Errors are never billed. Identical calls within 2 minutes (or any call with the same idempotency_key) return the cached result for free. Default caps per wallet: 2000 calls and $5 per day, 60 calls per minute.
