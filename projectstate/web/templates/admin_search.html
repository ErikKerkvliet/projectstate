How to read this: a zero hit means the agent asked and got nothing; a re-query means it rephrased right away (proxy for "the first answer was not it"). OR fallback means the strict query missed and a looser one was used. If zero-hit + re-query stay above ~25–30% on real traffic, keyword search is not enough and embeddings (or query expansion) should be added. Below that, FTS5 is doing its job and vectors would be cost without benefit.
